# Fontes oficiais consultadas

- Microsoft AI learning hub: https://learn.microsoft.com/en-us/ai/ — hub oficial com trilhas autodirigidas e recursos para funções técnicas e de negócio.
- Microsoft Azure AI Fundamentals: https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-fundamentals/ — página oficial que separa preparação autodirigida de exame AI-901 pago.
- Microsoft Applied Skills: https://learn.microsoft.com/en-us/credentials/applied-skills/ — credenciais práticas baseadas em avaliações interativas de laboratório.
- Microsoft Credentials AI Challenge: https://learn.microsoft.com/en-us/credentials/microsoft-credentials-ai-challenge — referência oficial para Applied Skills focadas em IA e indicação de avaliações gratuitas no período descrito pela página.
- Google Skills — Beginner: Introduction to Generative AI: https://www.skills.google/paths/118 — percurso oficial de cinco atividades sobre IA generativa e IA responsável.
- Google Skills — subscrições: https://www.skills.google/subscriptions — página oficial que apresenta o plano Starter sem custo, com créditos limitados e acesso a badges conforme disponibilidade.
- Google Cloud Computing Foundations: https://www.skills.google/paths/36 — percurso oficial de fundamentos de cloud.
- AWS Skill Builder — recursos gratuitos: https://skillbuilder.aws/search?page=1&accessTier=free — catálogo oficial filtrado por acesso gratuito.
- AWS Digital Training: https://aws.amazon.com/training/digital/ — página oficial que distingue cursos digitais gratuitos de experiências e assinaturas pagas.
- Kaggle Learn certificates: https://www.kaggle.com/learn-course-certificates — página oficial que informa certificado de conclusão para cursos finalizados.
- Hugging Face NLP Course: https://huggingface.co/learn/nlp-course/chapter1/1 — curso aberto oficial; não é apresentado como certificação profissional.
- Google Machine Learning Crash Course — redes neurais: https://developers.google.com/machine-learning/crash-course/neural-networks — material oficial sobre convoluções e pooling.
- OpenCV oficial: https://opencv.org/ e https://www.youtube.com/@opencvofficial — a plataforma aponta para as páginas oficiais, sem copiar ou redistribuir vídeos.
- DeepLearning.AI — playlist CNN: https://www.youtube.com/playlist?list=PLkDaE6sCZn6Gl29AoE31iwdVwSG-KnDzF — playlist pública associada ao conteúdo oficial da DeepLearning.AI; acesso depende das condições do canal.
- Google Cloud Generative AI: https://cloud.google.com/ai/generative-ai — página oficial com materiais e vídeos sobre IA generativa.
