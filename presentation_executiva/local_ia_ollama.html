Data Sovereignty // Local AI

Privacidade e Execução Local com Ollama

Soberania de Dados

Processamento local completo, garantindo que conversas e memórias nunca saiam da infraestrutura do aluno.

Latência Reduzida

Respostas instantâneas sem dependência de conexões externas ou filas de provedores de nuvem.

Custo Zero de API

Utilização ilimitada de modelos como Llama 3 e Mistral sem taxas por token ou assinaturas mensais.

Guia de Implementação

1

Instalação do Ollama e download do modelo alvo:

ollama run llama3
2

Configuração do endpoint REST local no backend:

http://localhost:11434/api/chat
3

Adaptação do helper LLM para o formato Ollama:

// server/_core/llm.ts
invokeLocalLLM({ model: "llama3", ... })
